# LuckyGuy AI Plugin Developer Guide & Prompt

Use this prompt to generate extensions for **LuckyGuy Desktop** using AI (ChatGPT, Claude, Gemini, DeepSeek).

---

## 📋 Copy & Paste This Prompt to Your AI

```markdown
You are an expert JavaScript extension developer for LuckyGuy Desktop (an Electron/React media manager and streaming platform).
Your task is to build a complete LuckyGuy extension based on the specifications below.

### LuckyGuy Architecture Rules:
1. Every extension provides a manifest.json and an index.js.
2. The core platform is offline-first and neutral. All scrapers, stream decoders, and crawlers run via extensions.
3. Content Rating: Specify "all", "mature", or "18+" depending on content.
4. Dynamic Tab: If the extension provides a video portal or web interface, declare the `tab` object with title, icon, and url.
5. AdBlock Rules: Include an array of regex/glob patterns under `adBlockRules` to strip out popunders, banners, and malicious redirects.

### Plugin Manifest Template (manifest.json):
{
  "id": "unique-extension-id",
  "name": "Extension Display Name",
  "version": "1.0.0",
  "type": "portal", // "audio" | "video" | "portal" | "crawler"
  "rating": "all",  // "all" | "mature" | "18+"
  "description": "Short explanation of the plugin",
  "author": "Author Name",
  "entry": "index.js",
  "tab": {
    "title": "Sidebar Label",
    "icon": "Film", // Film, Sparkles, Compass
    "url": "https://example-source.com",
    "badge": "HD"
  },
  "capabilities": ["stream", "crawlPage", "adblock"],
  "supportedUrls": ["*://example-source.com/*"],
  "adBlockRules": [
    "*://*.popunder-ad.com/*",
    "*://*.trackers.net/*"
  ]
}

### Plugin Implementation Template (index.js):
module.exports = {
  isSupported(url) {
    return url && url.includes('example-source.com');
  },

  // 1. Single Video/Stream Resolver
  async resolve(url) {
    try {
      // Fetch and extract title, poster, and stream URL (MP4, HLS m3u8, or WebM)
      return {
        id: 'stream-id',
        title: 'Video Title',
        thumbnail: 'https://.../thumb.jpg',
        videoUrl: 'https://.../stream.m3u8',
        format: 'HLS', // "HLS" | "MP4"
        headers: {
          'Referer': 'https://example-source.com/',
          'User-Agent': 'Mozilla/5.0 ...'
        }
      };
    } catch (err) {
      return { error: `Resolution failed: ${err.message}` };
    }
  },

  // 2. Batch Webpage Crawler (Scan 50-200 videos from category/page)
  async crawlPage(pageUrl) {
    try {
      // Scrape video cards from the page
      return [
        {
          id: 'vid-1',
          title: 'Video Title',
          thumbnail: 'https://.../thumb.jpg',
          duration: '10:30',
          size: '~100 MB',
          url: 'https://example-source.com/watch?v=1'
        }
      ];
    } catch (err) {
      return [];
    }
  }
};

Now, please write the complete manifest.json and index.js for:
[DESCRIBE YOUR STREAMING WEBSITE, AUDIO SOURCE, OR CUSTOM PORTAL HERE]
```

## 🚀 How to Test & Run in LuckyGuy (2 Simple Ways)

### Way 1: Paste Code Directly Inside LuckyGuy
1. Open **LuckyGuy** → **Settings** → **Plugins & Extensions**.
2. Click the **Paste Code / JSON** button.
3. Paste the `manifest.json` code generated by the AI.
4. Click **Test & Save Script**.
5. Your custom tab appears in the left sidebar!

### Way 2: Install via GitHub URL
1. Push your `manifest.json` and `index.js` to any GitHub repository.
2. In LuckyGuy Settings, click **From URL** and paste:
   ```text
   https://raw.githubusercontent.com/<username>/<repo>/main/manifest.json
   ```
3. Click **Install Plugin**.
