Plugin SDK v2.1 Specification

The LuckyGuy Extension SDK allows any developer to mount web portals, crawl video collections, integrate custom players, and download media into dedicated folders without writing native C++ or Electron code.

1. Manifest Specification (manifest.json)

Every plugin must include a manifest.json defining its identity, permissions, dynamic tab layout, and capabilities.

{
  "id": "luckyguy-ext-custom",
  "name": "Custom Stream & Portal",
  "version": "2.1.0",
  "type": "portal",                 // "portal" | "audio" | "video" | "crawler"
  "rating": "all",                  // "all" | "mature" | "18+"
  "description": "High performance video and audio crawler.",
  "author": "Developer Name",
  "entry": "index.js",
  "mediaTypes": ["video", "audio"],
  "tab": {
    "title": "Custom Tab",
    "icon": "Youtube",              // Lucide icon name: Youtube, Film, Sparkles, Send, Music
    "url": "https://example.com",
    "viewLayout": "grid",           // "grid" | "list"
    "themeColor": "#FF0000",
    "badge": "HD"
  },
  "capabilities": [
    "stream",                       // Resolves direct playable video/audio URLs
    "crawlPage",                    // Scrapes video cards from web pages
    "download",                     // Supports multi-quality offline downloads
    "videoPlayer",                  // Renders in custom floating video player
    "metadata",                     // Provides title, author, and duration
    "search",                       // Integrates with global search bar
    "adblock"                       // Strips ads using engine rules
  ],
  "supportedUrls": [
    "*://*.example.com/*"
  ],
  "adBlockRules": [
    "*://*.adserver.com/*",
    "*://*tracker*/*"
  ]
}

2. Lifecycle Methods (index.js)

The entry file index.js exports lifecycle hooks invoked by the LuckyGuy engine.

module.exports = {
  // Check if given URL belongs to this extension
  isSupported(url) {
    return url && url.includes('example.com');
  },

  // Resolve media details and streams for single video/audio
  async resolve(url, options = {}) {
    return {
      id: 'vid-123',
      title: 'Sample Video Title',
      author: 'Channel Name',
      thumbnail: 'https://example.com/poster.jpg',
      streamUrl: 'https://example.com/stream-1080p.mp4',
      // Multi-quality resolution dictionary
      streams: {
        '1080p': 'https://example.com/stream-1080p.mp4',
        '720p': 'https://example.com/stream-720p.mp4',
        '360p': 'https://example.com/stream-360p.mp4'
      },
      // Dual-track DASH audio sync URL (optional)
      audioStreamUrl: null,
      format: 'MP4',
      formatType: 'VIDEO',
      headers: {
        'Referer': 'https://example.com/'
      }
    };
  },

  // Batch crawl video cards from a page URL
  async crawlPage(pageUrl) {
    return [
      {
        id: 'item-1',
        title: 'Video Title',
        author: 'Creator Name',
        thumbnail: 'https://example.com/thumb1.jpg',
        duration: '14:20',
        durationFormatted: '14:20',
        size: '~150 MB',
        url: 'https://example.com/watch?v=1',
        mediaType: 'video',
        quality: '1080p HD'
      }
    ];
  }
};

3. Advanced Engine Features in SDK v2.1

Multi-Quality Stream Mapping

Provide a streams map with resolutions like 1080p, 720p, 480p. The in-app video player automatically displays a resolution picker.

DASH Synchronized Audio Track

If a source separates video and audio tracks (like YouTube), set audioStreamUrl. The player synchronizes playback and volume across both elements.

Persistent Companion Thumbnails

The engine automatically writes a companion <title>.jpg alongside downloaded videos, preserving library cards offline forever even when user cache is cleared.

Dynamic Subfolder Routing

Extensions can specify a customFolder or route into dedicated folders like Videos\YouTube or Videos\Adult\PornHub.
