Plugin & Extension SDK

Declarative Manifests • Stream Resolvers • Batch Crawlers • AdBlock Rules

1. Extension Manifest (manifest.json)

Every extension provides a manifest.json that tells LuckyGuy about its identity, permissions, dynamic sidebar presentation, and ad blocking rules:

manifest.json Template 
{
  "id": "luckyguy-ext-archive-movies",
  "name": "Archive Cinema & Open Movies",
  "version": "1.0.0",
  "type": "portal",             // "portal" | "audio" | "video" | "crawler"
  "rating": "all",              // "all" | "mature" | "18+"
  "enabled": false,             // Must default to false on install
  "description": "Stream public cinema and documentaries with ad blocking.",
  "author": "Open Archive Community",
  "entry": "index.js",
  "tab": {
    "title": "Open Cinema",     // Displayed in sidebar navigation
    "icon": "Film",             // Lucide icon name (Film, Music, Radio, etc.)
    "url": "https://archive.org/details/movies",
    "badge": "HD"               // Optional status pill
  },
  "capabilities": ["stream", "crawlPage", "adblock"],
  "supportedUrls": [
    "*://archive.org/details/*",
    "*://ia80*.*.archive.org/*"
  ],
  "adBlockRules": [
    "*://*.doubleclick.net/*",
    "*://*.popunder*/*",
    "*://*.adservice*/*"
  ]
}

Field Definitions:

  • id (String, required): Unique identifier in kebab-case.
  • rating (String): Content rating flag ("all", "mature", or "18+").
  • tab (Object, optional): When supplied, LuckyGuy automatically adds a dedicated tab to the sidebar navigation.
  • adBlockRules (Array): Glob and URL matching patterns blocked from loading in the webview.

2. Runtime Implementation (index.js)

The entry script index.js implements the resolver and crawler lifecycle methods:

index.js Implementation 
module.exports = {
  // 1. URL Support Check
  isSupported(url) {
    return url && url.includes('archive.org');
  },

  // 2. Single Stream Resolver
  async resolve(url) {
    try {
      const match = url.match(/\/details\/([^/?#]+)/);
      const identifier = match ? match[1] : 'sample-media';

      return {
        id: identifier,
        title: `Archive Cinema: ${identifier.replace(/[-_]/g, ' ')}`,
        thumbnail: `https://archive.org/services/img/${identifier}`,
        videoUrl: `https://archive.org/download/${identifier}/${identifier}.mp4`,
        format: 'MP4', // "MP4" | "HLS" | "WEBM"
        duration: '1h 32m',
        quality: '1080p',
        headers: {
          'Referer': 'https://archive.org/',
          'User-Agent': 'LuckyGuy-Desktop/1.0'
        }
      };
    } catch (err) {
      return { error: 'Resolution failed: ' + err.message };
    }
  },

  // 3. Batch Webpage Crawler (50 - 200 items)
  async crawlPage(url) {
    try {
      const items = [
        {
          id: 'movie-101',
          title: 'Night of the Living Dead (1968)',
          thumbnail: 'https://.../thumb.jpg',
          streamUrl: 'https://.../stream.mp4',
          duration: '1h 36m'
        }
      ];
      return { success: true, count: items.length, items };
    } catch (err) {
      return { success: false, error: err.message, items: [] };
    }
  }
};

3. Testing Plugins: Zero-Friction Paste & Run

You don't need a code editor, local compiler, or Git repository to test or run extensions:

  1. Open LuckyGuy Desktop → Preferences → Plugins & Extensions.
  2. Click "Paste Code / JSON".
  3. Paste your manifest JSON or JS script directly into the box. Markdown code blocks (```json) are cleaned up automatically.
  4. Click "Test & Save Script" to validate syntax and save.
  5. Toggle the switch ON to activate the tab in your sidebar!
