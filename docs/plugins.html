Plugins & Extensions SDK

Complete guide to building, installing, and managing modular audio and video extensions for LuckyGuy Desktop.

1 Master URL to Index Everything (All-in-One Registry)

Instead of installing extensions one-by-one, you can index and install all extensions at once using the master index URL. All extensions install disabled by default for complete user privacy and choice:

In the app: Open Settings → Plugins → Click "Index All Official Extensions".

Official Extensions Catalog

Every extension runs in an isolated sandbox, communicates via strictly defined SDK interfaces, and requires zero compilation or build steps.

🎵 Universal Audio Engine Core Streaming Multi-Service

Unified audio pipeline combining YouTube HD, Spotify rich metadata, JioSaavn 320kbps lossless CDN, and SoundCloud into a single auto-fallback stream resolver.

🎬 Archive Movies & Cinema Portal Sidebar Tab Public Domain

Stream and batch download thousands of public-domain feature films, historic broadcasts, and open-source movies from the Internet Archive with ad-blocker.

📻 Worldwide Live Radio Hub Sidebar Tab 30,000+ Stations

Direct playback of 30,000+ live radio broadcasts across 190+ countries with search by genre, codec (MP3/AAC), and country.

🔞 Pornhub Video Portal Rating: 18+

Video resolver and crawler extension with dedicated sidebar tab, multi-quality video player, and integrated back-end ad blocking.

How to Install in LuckyGuy Desktop:

  1. Click "Copy URL" next to any extension above.
  2. Open LuckyGuy Desktop → click Settings (⚙️) → select Plugins.
  3. Paste the copied URL into Extension Manifest URL and click Install Plugin.
  4. Toggle the switch ON to enable the plugin!
