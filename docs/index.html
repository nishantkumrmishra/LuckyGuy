Neutral Core & Extensible Ecosystem

Offline-First • Zero Telemetry • User-Controlled

LuckyGuy is architected on a strict neutral core philosophy. The base desktop application contains no proprietary scrapers, adult portals, or telemetry. Instead, all media sources, dedicated sidebar tabs, ad-blockers, and crawlers run through modular, sandboxed extensions. Installed extensions are disabled by default, giving users complete freedom to activate only the features they choose.

Core Platform Capabilities

Dynamic Sidebar Tabs

Extensions declare dedicated sidebar tabs with isolated iframe portals and custom badge labels.

Back-End Ad Blocker

Integrated network rule filter blocking popunder ad networks, malicious redirects, and tracking scripts.

Batch Page Crawler

Scan 50 to 200 videos from any category page in seconds with multi-select queue downloads.

Appearance & Theme Studio

Customize fonts, 8-color curated palettes, custom hex hues, and border radii in real time.

In-App Paste & Run

Paste AI-generated JSON or scripts directly into Settings to test and run without external IDEs.

Private & Offline-First

All library databases, preferences, and downloaded audio remain 100% on your local Windows PC.

1. Plugin Manifest Specification (manifest.json)

Every extension provides a declarative manifest.json defining its identity, permissions, rating, and dynamic sidebar presentation.

manifest.json 
{
  "id": "luckyguy-ext-archive-movies",
  "name": "Archive Movies & Cinema Portal",
  "version": "1.0.0",
  "type": "portal",             // "portal" | "audio" | "video" | "crawler"
  "rating": "all",              // "all" | "mature" | "18+"
  "enabled": false,             // Always disabled by default on install
  "description": "Stream public cinema and documentaries with ad blocking.",
  "author": "Community Developer",
  "entry": "index.js",
  "tab": {
    "title": "Open Cinema",     // Sidebar tab title
    "icon": "Film",             // Navigation icon (Lucide)
    "url": "https://archive.org/details/movies",
    "badge": "HD"               // Optional badge pill
  },
  "capabilities": ["stream", "crawlPage", "adblock"],
  "supportedUrls": [
    "*://archive.org/details/*",
    "*://ia80*.*.archive.org/*"
  ],
  "adBlockRules": [
    "*://*.doubleclick.net/*",
    "*://*.popunder*/*",
    "*://*.adservice*/*"
  ]
}

🤖 AI Website Scanner & Generator Prompt

Anyone can build a custom LuckyGuy extension in seconds using ChatGPT, Claude, or Gemini. Simply copy the master developer prompt below, supply your target website URL, and paste the generated code directly into LuckyGuy's "Paste Code / JSON" box!

AI Master Prompt (Copy & Paste to ChatGPT / Claude / Gemini) 
You are an expert JavaScript extension engineer for LuckyGuy Desktop (Electron media platform).
Your task is to scan the following website and produce a 100% working LuckyGuy extension.

TARGET WEBSITE URL: [INSERT WEBSITE URL HERE]

SPECIFICATIONS:
1. Generate a compliant "manifest.json" with:
   - "id": kebab-case identifier
   - "name": clean human display name
   - "rating": "all", "mature", or "18+" depending on the site content
   - "tab": { "title": "Sidebar Label", "icon": "Film", "url": "...", "badge": "HD" }
   - "adBlockRules": array of regex/globs blocking popup ad networks and tracking scripts
   - "capabilities": ["stream", "crawlPage", "adblock"]

2. Generate a companion "index.js" with:
   - "isSupported(url)": returns boolean
   - "async resolve(url)": extracts video/audio stream URL (.mp4, .m3u8, or webm) and artwork
   - "async crawlPage(url)": scans 50-100 media items from the page for batch download

Provide the result with clean code and zero external dependencies.

⚡ Zero-Friction "Paste & Run" In-App Runner

No external IDE, Node compilation, or GitHub hosting is required to test or run extensions:

  1. Open LuckyGuy Desktop → Preferences → Plugins & Extensions.
  2. Click the "Paste Code / JSON" toggle.
  3. Paste the AI-generated JSON manifest or JavaScript script into the box (markdown code blocks are stripped automatically).
  4. Click "Test & Save Script". LuckyGuy immediately verifies the syntax and creates the plugin.
  5. Toggle the extension switch ON whenever you want to activate its dedicated tab and ad-blocker!

  // 2. Single Stream Resolver (invoked when user clicks or pastes media link)
  async resolve(url) {
    try {
      const match = url.match(/\/details\/([^/?#]+)/);
      const identifier = match ? match[1] : 'sample-media';
      return {
        id: identifier,
        title: `Archive Cinema: ${identifier.replace(/[-_]/g, ' ')}`,
        thumbnail: `https://archive.org/services/img/${identifier}`,
        videoUrl: `https://archive.org/download/${identifier}/${identifier}.mp4`,
        format: 'MP4', // "MP4" | "HLS" | "WEBM"
        duration: '1h 32m',
        quality: '1080p',
        headers: {
          'Referer': 'https://archive.org/',
          'User-Agent': 'LuckyGuy-Desktop/1.0'
        }
      };
    } catch (err) {
      return { error: 'Failed to resolve stream: ' + err.message };
    }
  },

  // 3. Batch Webpage Crawler (scans 50-200 media files for multi-select download)
  async crawlPage(url) {
    try {
      // Scrapes page DOM or internal API to return media list
      const items = [
        {
          id: 'movie-101',
          title: 'Night of the Living Dead (1968)',
          thumbnail: 'https://.../art.jpg',
          streamUrl: 'https://.../movie.mp4',
          duration: '1h 36m'
        }
      ];
      return { success: true, count: items.length, items };
    } catch (err) {
      return { success: false, error: err.message, items: [] };
    }

    // AI Prompt Copy Button
    const copyAiPromptBtn = document.getElementById('copyAiPromptBtn');
    const aiPromptText = document.getElementById('aiPromptText');
    if (copyAiPromptBtn && aiPromptText) {
      copyAiPromptBtn.addEventListener('click', () => {
        navigator.clipboard.writeText(aiPromptText.innerText).then(() => {
          copyAiPromptBtn.innerText = 'Prompt Copied!';
          setTimeout(() => { copyAiPromptBtn.innerText = 'Copy Master Prompt'; }, 2000);
        });
      });
    }

    // Interactive Theme Sandbox logic
    const themeColorPicker = document.getElementById('themeColorPicker');
    const themeColorLabel = document.getElementById('themeColorLabel');
    const themeFontSelect = document.getElementById('themeFontSelect');
    const themeRadiusSelect = document.getElementById('themeRadiusSelect');
    const themePreviewBox = document.getElementById('themePreviewBox');
    const copyThemeJsonBtn = document.getElementById('copyThemeJsonBtn');

    function updateSandboxPreview() {
      const color = themeColorPicker.value;
      const font = themeFontSelect.value;
      const radius = themeRadiusSelect.value;

      themeColorLabel.innerText = color;
      themePreviewBox.style.borderLeftColor = color;
      themePreviewBox.style.borderRadius = radius;
      themePreviewBox.style.fontFamily = font;
    }

    if (themeColorPicker && themeFontSelect && themeRadiusSelect) {
      themeColorPicker.addEventListener('input', updateSandboxPreview);
      themeFontSelect.addEventListener('change', updateSandboxPreview);
      themeRadiusSelect.addEventListener('change', updateSandboxPreview);
    }

    if (copyThemeJsonBtn) {
      copyThemeJsonBtn.addEventListener('click', () => {
        const themeJson = {
          name: "Custom Theme from Docs",
          mode: document.documentElement.getAttribute('data-theme') || 'light',
          accentColor: themeColorPicker.value,
          fontFamily: themeFontSelect.value,
          borderRadius: themeRadiusSelect.value,
          version: "1.0.0"
        };
        navigator.clipboard.writeText(JSON.stringify(themeJson, null, 2)).then(() => {
          copyThemeJsonBtn.innerText = 'Theme JSON Copied!';
          setTimeout(() => { copyThemeJsonBtn.innerText = 'Copy Theme JSON'; }, 2000);
        });
      });
    }

    // Sidebar navigation active state on scroll
    const navItems = document.querySelectorAll('.docs-nav-item');
    const sections = document.querySelectorAll('.doc-section');
    window.addEventListener('scroll', () => {
      let currentId = '';
      sections.forEach(sec => {
        const top = sec.offsetTop - 120;
        if (window.scrollY >= top) {
          currentId = sec.getAttribute('id');
        }
      });
      if (currentId) {
        navItems.forEach(item => {
          item.classList.toggle('active', item.getAttribute('href') === '#' + currentId);
        });
      }
    });
  }

3. Appearance & Custom Theme Studio SDK

In Preferences → Appearance & Theme Studio, you can configure every visual aspect of LuckyGuy:

  • Application Mode: Crisp Studio Light vs. Deep Obsidian Dark.
  • Accent Palette: Violet, Emerald, Ocean, Ruby Rose, Sunset Orange, Amber, Indigo, Slate, or any custom hex.
  • Typography: Inter (Clean Sans), System UI (Segoe UI), JetBrains Mono (Code), Geist Sans (Tech), Merriweather (Serif), Comic.
