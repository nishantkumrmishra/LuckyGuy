🚀 Neutral Core & Modular Philosophy

LuckyGuy is built on the fundamental principle that the base desktop application is strictly neutral, local-first, and contains zero proprietary scrapers, adult sources, or telemetry. All streaming portals, resolvers, and crawlers run through user-controlled extensions.

Selective Extension Activation: Extensions installed into LuckyGuy are disabled by default. Users have complete freedom to enable only the 1 or 2 extensions they choose, keeping all other features completely silent.

Key highlights of the ecosystem:

  • Zero-Lock-in: No hardcoded Spotify or proprietary API keys baked into the install binary.
  • Integrated Back-End AdBlocker: Dynamic tabs have full protection against popunders, tracker scripts, and redirect domains.
  • Batch Crawler Tool: Any extension can define a crawlPage(url) method to scan 50–200 items in seconds with batch multi-select downloading.

🔌 Plugin SDK: Manifest Specification

Every extension provides a declarative manifest.json. This file informs LuckyGuy about capabilities, content rating, sidebar tab presentation, and ad-blocking rules.

manifest.json 
{
  "id": "my-video-streamer",
  "name": "Open Cinema Stream Hub",
  "version": "1.0.0",
  "type": "portal",             // "portal" | "audio" | "video" | "crawler"
  "rating": "all",              // "all" | "mature" | "18+"
  "description": "Stream public cinema and documentaries with ad blocking.",
  "author": "Community Developer",
  "entry": "index.js",
  "tab": {
    "title": "Cinema Hub",      // Displayed in sidebar navigation
    "icon": "Film",             // Lucide icon name
    "url": "https://archive.org/details/movies",
    "badge": "HD"               // Optional pill badge
  },
  "capabilities": ["stream", "crawlPage", "adblock"],
  "supportedUrls": ["*://archive.org/details/*"],
  "adBlockRules": [
    "*://*.doubleclick.net/*",
    "*://*.popunder*/*",
    "*://*.adservice*/*"
  ]
}

⚡ Runtime Lifecycle & Methods

The companion index.js file exports three lightweight asynchronous methods:

index.js 
module.exports = {
  // 1. URL matcher
  isSupported(url) {
    return url && url.includes('archive.org');
  },

  // 2. Single Stream Resolver (invoked when user clicks or pastes URL)
  async resolve(url) {
    try {
      return {
        id: "video-101",
        title: "Night of the Living Dead (1968)",
        thumbnail: "https://.../poster.jpg",
        videoUrl: "https://.../stream.mp4", // Or HLS .m3u8 playlist
        format: "MP4",
        duration: "1h 36m",
        headers: { "Referer": "https://archive.org/" }
      };
    } catch (err) {
      return { error: "Stream resolution failed: " + err.message };
    }
  },

  // 3. Batch Webpage Crawler (scans 50-200 videos from category/page)
  async crawlPage(url) {
    return {
      success: true,
      count: 24,
      items: [
        {
          id: "item-1",
          title: "Metropolis (1927)",
          thumbnail: "https://.../art.jpg",
          streamUrl: "https://.../video.mp4",
          duration: "2h 28m"
        }
      ]
    };
  }
};

🤖 AI Website Scanner & Generator Prompt

Anyone can build a custom LuckyGuy extension in seconds using ChatGPT, Claude, or Gemini. Simply copy the master developer prompt below, supply your target website URL, and paste the generated code directly into LuckyGuy's "Paste Code / JSON" box!

AI Master Prompt (Copy & Paste to ChatGPT / Claude / Gemini) 
You are an expert JavaScript extension engineer for LuckyGuy Desktop (Electron media platform).
Your task is to scan the following website and produce a 100% working LuckyGuy extension.

TARGET WEBSITE URL: [INSERT WEBSITE URL HERE]

SPECIFICATIONS:
1. Generate a compliant "manifest.json" with:
   - "id": kebab-case identifier
   - "name": clean human display name
   - "rating": "all", "mature", or "18+" depending on the site content
   - "tab": { "title": "Sidebar Label", "icon": "Film", "url": "...", "badge": "HD" }
   - "adBlockRules": array of regex/globs blocking popup ad networks and tracking scripts
   - "capabilities": ["stream", "crawlPage", "adblock"]

2. Generate a companion "index.js" with:
   - "isSupported(url)": returns boolean
   - "async resolve(url)": extracts video/audio stream URL (.mp4, .m3u8, or webm) and artwork
   - "async crawlPage(url)": scans 50-100 media items from the page for batch download

Provide the result with clean code and zero external dependencies.

⚡ Zero-Friction "Paste & Run" In-App Runner

No external IDE, Node compilation, or GitHub hosting is required to test or run extensions:

  1. Open LuckyGuy Desktop → Preferences → Plugins & Extensions.
  2. Click the "Paste Code / JSON" toggle.
  3. Paste the AI-generated JSON manifest or JavaScript script into the box (markdown code blocks are stripped automatically).
  4. Click "Test & Save Script". LuckyGuy immediately verifies the syntax and creates the plugin.
  5. Toggle the extension switch ON whenever you want to activate its dedicated tab and ad-blocker!
