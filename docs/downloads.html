System Requirements

  • Operating System: Windows 10 (1809+) or Windows 11 (64-bit architecture).
  • RAM: 4 GB minimum (8 GB recommended for heavy batch audio crawling).
  • Disk Space: 150 MB for the core application (audio storage depends on library size).
  • Network: Broadband internet connection for initial stream resolution and CDN fetching.

Building from Source

You can also clone and run LuckyGuy from source using Node.js & npm:

PowerShell / Terminal 
git clone https://github.com/nishantkumrmishra/LuckyGuy.git
cd LuckyGuy
npm install
npm run dev
