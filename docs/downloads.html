What's New in Version 1.1.0

  • YouTube Media Portal Extension: Powered by yt-dlp with multi-quality streams (1080p, 720p, 360p) and synchronized DASH audio streaming.
  • Standard MP4 Encoding (Fixed 0xC00D3E84): YouTube downloads now multiplex video and audio into clean, standard MP4 files via FFmpeg, natively playable in Windows Media Player.
  • Automatic Subfolder Organization: YouTube video downloads automatically save to Videos\YouTube and index directly into the Videos library.
  • Persistent Companion Thumbnails: Every downloaded video automatically saves a high-res companion .jpg thumbnail on disk, keeping offline cards visible even if user cache is cleared.
  • Plugin SDK v2.1: Added multi-resolution stream mappings, dual-track audio sync interface, and subfolder routing in the extension developer framework.

System Requirements

  • Operating System: Windows 10 (1809+) or Windows 11 (64-bit architecture).
  • RAM: 4 GB minimum (8 GB recommended for heavy batch media crawling).
  • Disk Space: 150 MB for the core application (storage depends on downloaded media).
  • Network: Broadband internet connection for initial stream resolution and CDN fetching.

Building from Source

You can also clone and run LuckyGuy from source using Node.js & npm:

PowerShell / Terminal 
git clone https://github.com/nishantkumrmishra/LuckyGuy.git
cd LuckyGuy
npm install
npm run dev
