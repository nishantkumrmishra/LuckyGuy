Architecture & Privacy

Neutral Core Design • Local-First Architecture • Sandboxed Extensions

1. The Neutral Core Baseline

Unlike conventional desktop media clients that ship with proprietary API keys, telemetry trackers, or hardcoded streaming scrapers, LuckyGuy maintains a strictly neutral baseline.

When you download and launch LuckyGuy on a clean Windows machine:

  • Zero Telemetry: No analytics pings, no tracking pixels, and no phone-home servers.
  • No Hardcoded Scrapers: Third-party media sources or adult portals are never pre-baked into the binary.
  • Offline Native Storage: All library databases, playlists, track tags, and preferences reside solely on your PC.

2. Security: Disabled by Default

Whenever a user installs an extension—whether by pasting a script directly or supplying a community URL—it is registered in an inactive state (enabled: false).

This ensures that:

  • Extensions cannot execute background requests without explicit user consent.
  • Users can selectively toggle on one or two specific extensions and leave the rest disabled.
  • Deleting an extension completely purges its cache and unbinds its custom sidebar tabs.

3. Sandboxed Dynamic Tabs & Ad-Blocker

When an enabled extension provides a custom web portal tab, LuckyGuy renders it within an isolated container:

  • Back-End Ad Blocking: The Electron session hooks request traffic against the extension's declared adBlockRules, filtering popunders, tracking scripts, and malicious redirects before they load.
  • Custom Blacklist Management: Users can view blocked request counters and add custom domain blacklist filters live in the tab header.
  • Audio/Video Isolation: The portal runs separately from the native audio engine, ensuring uninterrupted music playback.

4. Data Storage & Local Cache

All data in LuckyGuy is completely transparent and inspectable:

Local Data Locations 
Preferences & Extensions: localStorage ("luckyguy-extensions", "luckyguy-appearance")
Downloaded Audio Files:   C:\Users\<Username>\Music\ (or custom selected folder)
Automated Genre Folders:  C:\Users\<Username>\Music\<Genre>\<Artist> - <Title>.mp3
