AI Website Scanner & Generator

Scan Any Media Website With AI • Generate Clean Extensions in Seconds

How to Use the AI Scanner

You don't need to write code by hand. Any modern AI (ChatGPT, Claude, Gemini, DeepSeek) can scan a media website and generate a complete LuckyGuy plugin using this master prompt:

  1. Copy the Master Prompt below.
  2. Paste it into ChatGPT / Claude / Gemini along with the URL or HTML sample of the website you want to stream.
  3. Copy the AI's generated JSON or JS output.
  4. Open LuckyGuy Desktop → Preferences → Plugins & Extensions, choose "Paste Code / JSON", and click "Test & Save Script".
  5. Toggle the plugin switch ON to immediately launch your custom tab and ad-blocker!

Master AI Developer Prompt

Copy and send this prompt to your AI assistant:

AI Master Prompt (Copy & Paste) 
You are an expert JavaScript extension engineer for LuckyGuy Desktop (an Electron/React media manager and streaming platform).
Your task is to scan the following media website and build a 100% compliant LuckyGuy extension.

TARGET WEBSITE URL: [INSERT TARGET WEBSITE OR PAGE URL HERE]

### LuckyGuy Architecture Rules:
1. Every extension provides a manifest.json and an index.js.
2. The core platform is offline-first and neutral. All scrapers, stream decoders, and crawlers run via extensions.
3. Content Rating: Specify "all", "mature", or "18+" depending on content.
4. Dynamic Tab: If the extension provides a video portal or web interface, declare the `tab` object with title, icon, and url.
5. AdBlock Rules: Include an array of regex/glob patterns under `adBlockRules` to strip out popunders, banners, and malicious redirects.
6. The extension MUST default to "enabled": false on install.

### Plugin Manifest Template (manifest.json):
{
  "id": "custom-extension-id",
  "name": "Extension Display Name",
  "version": "1.0.0",
  "type": "portal",
  "rating": "all",
  "enabled": false,
  "description": "Short explanation of the plugin",
  "author": "Author Name",
  "entry": "index.js",
  "tab": {
    "title": "Sidebar Label",
    "icon": "Film",
    "url": "https://target-site.com",
    "badge": "HD"
  },
  "capabilities": ["stream", "crawlPage", "adblock"],
  "supportedUrls": ["*://target-site.com/*"],
  "adBlockRules": [
    "*://*.popunder-ad.com/*",
    "*://*.trackers.net/*"
  ]
}

### Plugin Implementation Template (index.js):
module.exports = {
  isSupported(url) {
    return url && url.includes('target-site.com');
  },

  async resolve(url) {
    try {
      // Extract media stream (.mp4, .m3u8, or webm) and artwork
      return {
        id: "video-id",
        title: "Video Title",
        thumbnail: "https://.../thumb.jpg",
        videoUrl: "https://.../stream.mp4",
        format: "MP4",
        headers: { "Referer": "https://target-site.com/" }
      };
    } catch (err) {
      return { error: "Stream resolution failed: " + err.message };
    }
  },

  async crawlPage(url) {
    // Scrape 50-100 media items from the page for batch multi-select downloading
    return {
      success: true,
      count: 20,
      items: [
        {
          id: "item-1",
          title: "Sample Video",
          thumbnail: "https://.../thumb.jpg",
          streamUrl: "https://.../stream.mp4",
          duration: "10m"
        }
      ]
    };
  }
};

Output both files cleanly with zero external npm dependencies.

Troubleshooting & Best Practices

  • HLS (.m3u8) Streams: If the video uses HLS streaming, set format: "HLS" and provide the .m3u8 manifest URL in videoUrl.
  • HTTP Referer Headers: Many video hosts require a matching Referer or User-Agent header. Always return headers: { 'Referer': 'https://target-site.com/' } in resolve().
  • AdBlock Patterns: If a website opens annoying popups, inspect the popup domains and add them to adBlockRules (e.g. "*://*popcash*/*", "*://*adservice*/*").
