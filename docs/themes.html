Appearance & Theme Studio SDK

Monochrome Accents • Typography Stacks • Corner Curvature • Theme Presets

1. In-App Theme Studio Features

In LuckyGuy Desktop → Preferences → Appearance & Theme Studio, every visual component responds live:

  • Theme Modes: Crisp Studio Light vs. Deep Obsidian Dark.
  • Primary Palette: Violet, Emerald, Ocean, Ruby Rose, Sunset Orange, Amber, Indigo, Slate, or custom hex color picker.
  • Typography: Inter, System UI (Segoe UI), JetBrains Mono, Geist Sans, Merriweather Serif, Comic.
  • Corner Curvature: Sharp (4px), Balanced (8px), Curved (14px), Pill (20px).
  • Import/Export Theme JSON: 1-click clipboard copy to share themes with others or paste community themes.

2. Theme JSON Specification

LuckyGuy themes are stored as simple JSON objects in localStorage and can be shared or pasted into the app:

theme.json 
{
  "name": "Cyberpunk Emerald",
  "mode": "dark",              // "light" | "dark"
  "accentColor": "#10b981",    // Any hex color string
  "fontFamily": "JetBrains Mono", // "Inter" | "JetBrains Mono" | "System UI" | "Geist Sans" | "Merriweather"
  "borderRadius": "4px",       // "4px" | "8px" | "14px" | "20px"
  "version": "1.0.0"
}
